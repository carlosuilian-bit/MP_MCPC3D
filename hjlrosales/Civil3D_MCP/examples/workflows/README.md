# Example workflows

Transcript-style sessions that combine several tools into a real task:

- `grading-workflow.md` - site grading & earthwork (inspect -> compare -> export)
- `corridor-review-workflow.md` - corridor analysis & daylighting check
- `quantity-takeoff-workflow.md` - quantity takeoff & CSV export

The exact tool names come from the live bridge manifest; run `tools/list` (or ask
your client) to see the catalog on your version.
